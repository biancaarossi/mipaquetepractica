# Idiomas oficiales por pais

Dataset que contiene informacion sobre los idiomas oficiales de
distintos paises. Para cada pais se indica el idioma oficial principal
y, cuando corresponde, un segundo idioma oficial.

## Usage

``` r
idiomas
```

## Format

Un data frame con 10 filas y 3 variables:

- pais:

  Nombre del pais

- idioma_oficial_1:

  Idioma oficial principal

- idioma_oficial_2:

  Segundo idioma oficial, si existe
